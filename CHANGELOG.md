# Changelog

## v0.1.0 — first public release

- Added the eight-tab UltraUniversalMod interface: Home, Search, Dialogues, Saves, Timeline, Gallery, Settings, and Updates.
- Added independent Russian and English interface text with an instant RU / EN switch on Home.
- Added official project and community links and author information.
- Corrected search paths when a value is reachable through both `store` and a direct variable.
- Prevented invalid stored search, save-page, appearance, and dialogue-history data from crashing the relevant views.
- Corrected display of save names containing a Ren'Py text-tag opening brace.
- Corrected the Home dialogue card so it describes the available export tool.
- Added attribution and full license texts for all six bundled font files.
